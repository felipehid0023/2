Consulta aplicada en Power Query

1. Origen: Viajes ×(combinar)× Vehículos ×(combinar)× Empresas_Transportistas
2. Filtro: Empresas_Transportistas[estado] = "Activo"
3. Columna personalizada: duracion_h = fecha_hora_llegada_real − fecha_hora_salida_real
4. Agrupar por: nombre_transportista → SUM(ingreso_flete_soles), SUM(duracion_h), COUNT(id_viaje)
5. Columna personalizada: soles_por_hora = ingreso_total / tiempo_total_h
6. Ordenar descendente por soles_por_hora

Limpieza previa que hizo posible esta consulta

  • ✓ Montos de flete con texto o comas ("S/ 1,164.98") convertidos a números reales antes de sumar
  • ✓ Filas de viajes duplicadas eliminadas para no inflar el conteo ni el ingreso
  • ✓ Fechas de salida/llegada normalizadas a un mismo formato para poder restarlas
  • ✓ Registros sin fecha de llegada real descartados de este cálculo (viaje no cerrado)
  • ✓ Nombres de empresas con espacios extra o mayúsculas inconsistentes estandarizados antes de agrupar
